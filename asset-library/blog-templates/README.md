# 착한거래 블로그 포스터 템플릿

핵심은 SVG 여부가 아니라 **반복 출력에서 같은 클로이가 유지되는 것**이다. 출력 시에는 등록된 캐릭터 PNG를 그대로 재사용하고 글·배경·배치만 바꾼다. 얼굴이나 몸을 매번 재생성하지 않는다. 이미지·폰트·CI·B안 참조는 SHA256로 묶으며 달라진 바이트가 있으면 중단한다. 생성 AI는 새 포즈/복장 후보 또는 별도 배경을 만드는 단계에서만 쓴다. 후보는 얼굴·체형·헤어·액세서리를 대조해 채택한 뒤 고정 자산으로 등록한다. 참조 생성 자체가 모든 각도의 동일 기하구조를 보장하는 것은 아니다.

`library.json`의 현재 패키지부터 읽는다. 레이아웃은 `layouts.mjs`, 색·폰트·좌표 규격은 `design-tokens.json`, AI 입력은 `content.schema.json`과 `examples.json`을 따른다. CI는 확정 P2 원본을 그대로 쓴다.

기본 형식은 표지·비교표·체크리스트·절차·주의사항·FAQ 여섯 가지다. 큰 제목·번호·명확한 정보 구획으로 전단지/포스터 느낌을 유지한다. 한 장에 설명을 계속 늘리지 않는다. 긴 내용은 여러 장으로 나눈다. 발표 자료에 옮길 때도 한 화면의 주장과 근거를 단순하게 유지한다.

## 고정할 것과 바꿀 것

- 고정: P2 CI 원본·종횡비, SUITE Heavy 제목, Noto Sans KR 본문, 64px 좌우 여백, 텍스트·인물 분리, 규격별 좌표와 크기.
- 바꿀 것: 제목·본문·항목, 준비된 배경 테마, 글 상황에 맞는 인물·복장·자세, 등록한 AI 생성 장면.
- 배경: 살구·하늘·세이지·라일락·크림을 순환한다. 주의사항은 짙은 바탕과 밝은 글자를 쓴다. P2 형광 마크와 본문 강조색은 원래 색을 유지한다.
- 인물: 표지는 상반신·사선·설명 동작을 우선한다. 네이비 수트·카디건·흰 수트·정비복을 글에 맞춰 고른다. 전신은 복장·구두·이동을 보여줄 때 쓴다. 무릎 위 차콜 펜슬스커트와 검정 펌프스의 비서형도 별도 활용한다. 필요 없는 장에는 인물을 넣지 않는다.
- 같은 배경·복장·포즈를 연속해서 반복하지 않는다. `vary.mjs`는 미지정 배경과 표지 상반신을 번갈아 채우며, 작성자가 지정한 값은 보존한다. 순환 오프셋을 다음 묶음으로 넘길 수 있다.

## 반복 제작

1. 다른 AI는 글의 문단 목적에 맞춰 형식을 고르고 `examples.json`처럼 JSON을 작성한다. 텍스트를 이미지 생성 모델에 그리게 하지 않는다.
2. `node vary.mjs draft.json jobs.json 0`으로 미지정 색과 인물을 채운다. 구체적으로 지정할 때는 `theme`, `character`를 직접 적는다. 인물 없이 만들려면 `character:null`을 명시한다.
3. `node render.mjs --input jobs.json --bundle . --output 새출력폴더`로 HTML·PNG를 만든다. 출력 폴더는 비어 있어야 한다. Playwright가 있는 Node와 Microsoft Edge를 쓴다. 현재 PC0/PC1 인계의 실행 경로는 각 `START-HERE`를 따른다.
4. 글자 넘침·누락된 폰트·이미지 오류·글자와 인물 겹침이 있으면 실패한다. 글자를 작게 줄이거나 잘라서 통과시키지 않는다. 문구를 줄이거나 장을 나눈다.
5. PNG를 블로그에 쓰고 HTML/JSON은 다음 제작의 원본으로 보관한다. 원고와 조건·수치·출처가 맞는지 확인한 뒤 게시한다. 이 도구는 사실 검증이나 게시를 대신하지 않는다.

AI로 만든 사진·장면은 별도 이미지 영역에 넣는다. 현재 예시는 가상 차량 장면이며 실제 차종·재고·차량 상태 증빙이 아니다. 새 자산은 먼저 `assets.json`에 상대 경로와 SHA256를 등록한다. 임의 URL·과거 거절된 캐릭터를 참조하지 않는다. 로봇 정면 정본과 사람형 B안 기준은 바꾸지 않는다.

본문은 텍스트로 조판하므로 HTML에서 바꿀 수 있다. 포스터 PNG는 완성 이미지이며 의미별 벡터는 아니다. 제공된 사람형 의상 SVG도 원본 해상도 픽셀 경로로, 관절 리그나 해상도에 무관한 새 형태 복원이 아니다. 자동 게시·예약·새 정본 승격은 포함하지 않는다.
