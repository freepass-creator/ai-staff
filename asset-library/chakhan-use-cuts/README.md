# 착한거래 최신 활용 컷

`library.json` → 공개 카탈로그 또는 저장소 상대경로의 카탈로그를 읽는다. 현재 전화 상담·태블릿 설명·오른쪽 안내 세 컷이다. 원본 URL·SHA·투명도·용도·배치 설명·ZIP이 들어 있다.

사용 브랜드는 착한거래다. 흰 외장·노란 발광·착한거래 이마 명찰·CLO-02 가슴 번호를 유지한다. 프리패스 보라색 세트를 대신 쓰거나 이미지를 다시 생성하지 않는다. PNG를 SHA로 확인한 뒤 문구·배경·위치만 구성한다. 프로필 사진 허용 목록이나 정면 캐릭터 정본을 대체하지 않는다.

다른 프로젝트는 ZIP을 받아 새 폴더에 풀거나 카탈로그의 PNG URL을 직접 가져간다. 특정 PC의 D 드라이브 경로가 필요하지 않다. 실제 계약·직원·차량 출고 증빙은 실제 자료를 사용한다.
