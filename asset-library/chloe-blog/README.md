# 클로이 블로그 이미지 제작 키트

현재 정본은 `robots/current.json`의 CLO-02 smooth-subtle-0.1이다. 기본형은 보라색, 착한거래형은 노란색이다. 이 라이브러리의 새 포즈는 **정본을 참조해 생성한 활용 이미지**이며 정본을 대체하지 않는다.

패키지 내부 시작점은 같은 폴더의 `AI-START-HERE.md`와 `index.html`이다. 웹 뷰어 `/library/`의 ‘전체 ZIP 받기’로 묶음을 내려받는다. 프로젝트에서 실제 보관 위치가 필요하면 `asset-library/chloe-blog/library.json`을 읽는다. `poses`에는 상황별 PNG가 있다(투명 또는 흰 배경 여부는 manifest의 alpha/background로 구분). `exports`에는 가로 1200×675 및 정사각 1080×1080 블로그 이미지가 있다. `refs`에는 최신 두 정본 PNG/SVG, `brand`에는 P2 CI와 SUITE 폰트가 있다.

다른 AI는 패키지의 `AI-START-HERE.md`, `identity-lock.json`, `prompts.json`부터 읽는다. 글을 쓸 때는 새 그림을 생성하기 전에 `manifest.json`의 usage_tags로 기존 이미지를 선택한다. 새 포즈가 필요하면 정본 PNG를 이미지 입력으로 반드시 첨부하고 해당 prompt를 사용한다. 텍스트 프롬프트만으로 재현을 보장하지 않는다.

## AI가 어떤 글에 쓸지 판단하는 설명

모든 이미지의 `editorial`에 실제 보이는 장면, 어울리는 글 주제와 문단, 사용 시점, 시선·대상, 글자 배치 여백, 배경 사용법, 피해야 하는 용도와 캡션 예를 기록한다. 사람이 읽는 전체 설명은 `AI-WRITER-USAGE.md`, 기계가 읽는 목록은 `usage-index.json`이다. 실제로 보이는 환경과 글에서 권장하는 상황을 구분한다.

AI의 기본 선택 파일은 글자가 추가되지 않은 `poses` 장면 PNG다. `exports`의 표지·본문 카드에는 이미 제목과 설명이 있으므로 manifest의 `copy`가 글의 내용과 맞을 때만 그대로 사용한다. 문구를 바꾸려면 copy를 수정하고 재출력한다. 같은 asset_id의 원본과 두 레이아웃은 동일한 장면 사용 설명을 공유한다.

문단 설명으로 기존 이미지 후보를 찾을 수 있다:

```powershell
node select.mjs . "고객과 계약서를 함께 확인하는 문단"
```

PC0 로컬 조회는 `/api/characters/library/select?q=문단설명`이다. 후보마다 사용 설명·선택 키워드·파일·SHA256을 반환한다. `alpha=1`은 투명 파일만, `camera=측면` 및 `target=고객`은 명시한 조건만 고른다. 실차·계약서 증빙이 필요한 요청은 그림으로 대체하지 않는다. 이 기능은 규칙 기반 후보 검색이며 실제 그림과 문단의 의미를 최종 확인해야 한다.

조건에 맞지 않거나 약하게만 일치하면 무리하게 이미지를 배정하지 않는다. `needs_new_scene` 또는 `needs_more_context`를 반환한다. 호출하는 AI는 필요한 새 장면을 `production-plan.json`의 대기 목록에 기록한다. 선택 API 자체는 읽기 전용이며 새 이미지 생성·게시·예약을 실행하지 않는다.

새 장면을 추가할 때는 manifest의 행동·대상·시선·표정·구도와 함께 `usage-rules.json`에 같은 ID의 사용 설명을 등록한다. 설명이 없는 새 ID는 빌드에서 거부한다. 생성 결과가 주문과 다르면 설명을 사실대로 고치거나 이미지를 수정한 뒤 등록한다.

장면 선택은 `camera_angle`과 `framing`도 함께 확인한다. 측면·후면·뒤쪽 사선·어깨 너머 시점과 상반신·앉은 자세·걷기·악수 장면을 지원한다. `gallery.mjs`가 새 구도 시리즈를 맨 앞에 놓고 카메라 시점 검색·필터를 제공한다. 정면 참조 이미지는 디자인 기준이며 새 그림의 카메라를 정면에 고정하는 지시가 아니다. 뒷면의 숨은 구조는 활용 이미지용 추정이며 새 정본이나 3D 설계도로 사용하지 않는다.

제목·본문은 `manifest.json`의 copy만 수정한다. 캐릭터 그림에 새 글씨·가격을 덧그리지 않는다. 고정 가격·최저가·심사 통과 보장 등을 이미지에 넣지 않는다. 법률·견적 조건은 실제 자료를 확인한 뒤 글 본문에서 설명한다.

## 이미지 다시 출력

Node.js와 Playwright, 해당 브라우저가 있는 환경에서:

```powershell
# 패키지를 푼 폴더에서
node build.mjs .
```

모듈이 별도 경로에 있으면 `CHLOE_PLAYWRIGHT_MODULE`에 playwright의 index.mjs 경로를 지정한다. 기본 브라우저는 Edge이며 `CHLOE_BROWSER_CHANNEL`로 바꿀 수 있다. 기존 PNG 포즈는 바꾸지 않고 HTML/CSS로 레이아웃을 출력한다. 소스 이미지 해시와 텍스트·이미지 겹침을 확인한 뒤 저장한다.

정본 SVG는 고정 정면의 코드 자산이다. 새 포즈 PNG를 벡터나 3D 리그라고 표시하지 않는다. 표지 출력은 검증된 정본 디자인을 참조하는 생성형 파생 이미지이며 모든 픽셀이 정본과 같은 것은 아니다. 홈페이지·블로그 자동 게시와 공개 업로드는 이 키트에 포함하지 않는다.

손 기준은 identity-lock.json과 최신 정본을 따릅니다. 반려 01-welcome은 현재 공유의 원본·조판·프롬프트에서 제외했습니다. 원본 이력은 보존하지만 선택·URL·공유 ZIP으로 제공하지 않습니다.
