# 사람형 클로이 이미지 사용

진입점은 `library.json`, 캐릭터 기준은 `characters/클로이/character.json`이다. 소속 프리패스, 활용 브랜드 착한거래다. 로봇 이미지는 기존 `asset-library/chloe-blog/library.json`에서 따로 고른다.

`http://127.0.0.1:54640/human/`에서 보고 `/human/download.zip`으로 가져간다. 다른 PC의 `127.0.0.1`은 PC0가 아니다. PC1에서는 복사된 패키지의 `index.html`을 직접 연다. PC0 서버를 외부에 공개하지 않는다.

글쓴이는 먼저 문단의 행동·대상·촬영 범위를 적고 `/api/characters/human/select?q=문단설명`으로 후보를 찾는다. 규칙 기반 검색이며 `matched`도 제작자의 장면 확인이 필요하다. `weak_match`는 일반 단어만 맞은 후보, `no_match`는 쓸 그림이 없다는 뜻이다. 실제 증빙이 필요하면 `evidence=1`로 조회해 `real_source_required`를 반환받는다. 일러스트로 계약 체결·차량 상태·고객 후기 사실을 증명하지 않는다.

각 항목의 `usage`, `layout`, `camera_angle`, `framing`을 읽는다. 같은 전신 정면만 반복하지 않고 상반신·앉기·사선·후면을 섞는다. 로봇·사람형·차량·정보 그림을 문단에 맞게 고른다. 고정 비율은 없다. 같은 컷을 연속 표지로 반복하지 않는다. 머리핀·옷핀·이어피스 방향이 바뀌므로 좌우 반전하지 않는다.

블로그 업로드에는 투명 PNG를 우선 사용한다. SVG는 PNG를 내장하지 않는 네이티브 해상도 픽셀 경로다. 원본 질감을 보존하는 정적 컷이며, 작고 의미별로 편집 가능한 곡선 벡터나 관절 리그가 아니다. SVG는 용량이 크므로 페이지에 여러 개를 동시에 인라인으로 넣지 않는다.

새 그림 제작은 패키지의 `AI-START-HERE.md`, `identity-lock.json`, 선택 B안 시트, `prompts.json`을 함께 쓴다. 얼굴·단발·흰 수트·차콜 이너·흰검노랑 배지·노랑 포인트를 유지한다. 직무에 맞는 복장 파생은 허용된다. 거절된 얼굴이나 옛 로봇 비교는 재사용하지 않는다.

자동 생성·예약·업로드는 설치하지 않았다. 앞으로 만들 장면은 `production-plan.json`에 기록하고 실제 PNG/SVG와 해시 검증이 끝난 것만 사용 가능 목록에 넣는다.
