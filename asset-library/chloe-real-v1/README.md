# CLO-02 실사 제작 정본

클로이 실사 외형 리비전은 `2026-11-20.1`이다. 대표는 2026-11-20에 얼굴·전신 참조팩을 실사 정본으로 지정했다. `current.json`은 역할, 참조 순서, 파일 해시를 기록한다. 원본 PNG와 적용 지시문은 그 파일에 적힌 권한 제한 콘텐츠 라이브러리 경로에 있다. 다른 PC에서는 같은 ZIP을 내려받아 풀고 다음 명령을 실행한다.

    node asset-library/chloe-real-v1/resolve.mjs <압축을-푼-정본-폴더> full

`face`는 얼굴 제작, `full`은 얼굴과 정장 전신 제작, `fitting`은 체형·디테일 검토, `all`은 등록 사진 전체 무결성 확인에 쓴다. 결과 JSON의 파일 순서를 따른다. `face-master`가 얼굴 1순위이며 `face-front`는 검수한 정면 보조 사진이다. `suit-body-front`는 앞서 승인된 이미지의 고정 정면 체형이다. 피팅 자료는 기존 시트에서 분리한 상의·하의 착용 실루엣과 디테일이다. 시트 해상도와 시점 차이가 있으므로 실제 신체 치수나 3D 관절 데이터로 해석하지 않는다. 생성 결과는 별도 얼굴·실루엣 대조가 필요하다.

이 등록은 CLO-02 실사 제작용이다. 기존 로봇 및 인물형 포즈 공급 경로의 ID는 각각 독립적이다.

45도에 가까운 사선 얼굴은 [보조 참조 기록](face-angle-45.json)에 있다. 정면 얼굴 원본을 첫 번째로 넣은 뒤 이 사진을 사선 얼굴에만 추가한다. 이 사진의 얼굴 검사값은 0.720이다. 사선·측면·후면 전신에는 이 검사를 적용한 것으로 간주하지 않는다.

사선 얼굴 PNG를 압축을 푼 정본 폴더의 `angles/face-angle-45-v1/three-quarter-face.png`에 두고 다음 명령을 실행하면 두 사진의 순서와 경로가 출력된다. 파일이 없거나 해시가 다르면 중단한다.

    node asset-library/chloe-real-v1/resolve.mjs <정본-폴더> face-45

[실사 디테일 정본 기록](face-detail-v1.json)은 정면 확대 질감 참조다. 얼굴 대조 0.632를 통과했다. 코와 볼의 모공과 은은한 윤기, 눈동자와 광원 반사, 잔머리와 가르마의 기준으로 쓴다. 디테일 사진을 `details/face-detail-v1/chloe-detail-master.png`에 추가하면 정면·사선의 가슴 위 및 얼굴 컷에서 자동으로 사용한다. 얼굴 구조는 기존 얼굴 정본 기준이다.

    node asset-library/chloe-real-v1/resolve.mjs <정본-폴더> face-detail

## 말로 촬영 지시하기

포즈 목록이 있는 캐릭터 파일 v2를 푼 뒤, 촬영 문장에서 구도·높이·화면 범위를 읽어 파일 경로와 생성 지시문을 출력한다.

    node asset-library/chloe-real-v1/shot.mjs <캐릭터팩> "앉아서 오른쪽 45도 눈높이로 무릎까지 찍어줘"
    node asset-library/chloe-real-v1/shot.mjs <캐릭터팩> "그 상태에서 카메라만 더 가까이" --from <이전-촬영.json> --frame <검수한-이미지.png>

기본 자세는 서기다. 앉기, 다리 꼬아 앉기, 무릎 꿇기와 정면·좌우 사선·측면·후면, 눈높이·하이·로 앵글, 전신·무릎·허리·가슴·얼굴 범위를 읽는다. 가까이/멀리는 같은 장면에서 화면 범위를 한 단계 바꾼다. 새 배경과 의상은 새 촬영으로 시작한다. 오른쪽 사선 전용 얼굴만 검증되어 있으며 왼쪽 사선은 정면 얼굴을 보조로 사용한다.

출력의 imagegen 항목을 이미지 생성 도구에 전달한다. 명령 자체는 이미지를 생성하거나 정본으로 승인하지 않는다. 촬영 뒤 얼굴·화면 범위·자세·장면 연속성을 확인한다.

조명·배경만 바꾸려면 앞 컷을 얼굴 검수한 뒤, 같은 컷과 검수 기록을 함께 준다. 얼굴 검수 기록은 Studio actor-kit의 `face_gate.py <얼굴-정본-절대경로> <앞-컷-절대경로> --json` 출력으로 만들 수 있다. 검수 후 파일이 바뀌거나 얼굴 판정이 통과하지 않으면 편집 지시 생성을 중단한다.

    node asset-library/chloe-real-v1/review.mjs <앞-컷.png> <검수-출력.json> > review.json
    node asset-library/chloe-real-v1/shot.mjs <캐릭터팩> "배경과 조명을 저녁 실내로 바꿔줘" --from <이전-촬영.json> --frame <앞-컷.png> --review review.json

조명·배경 편집은 구도를 그대로 두고 앞 컷의 얼굴과 자세를 참고한다. 카메라 변경과 조명·배경 변경은 한 번씩 따로 요청한다. 출력 결과는 얼굴과 연속성을 다시 확인한다.

## 부위별 설계도와 조합

[부위 설계도 데이터](blueprint.json)는 같은 클로이 리비전에서 얼굴, 피부, 눈, 머리, 몸통, 팔·손, 다리와 구두를 포함한 14가지 참조를 지정한다. 각 항목은 원본 파일, 원본의 픽셀 사각형, 참조할 수 있는 범위를 가진다. 전신의 점은 정수리와 구두 접지점을 기준으로 표시한 수동 2D 표시이며 물리적인 신체 치수는 아니다.

    node asset-library/chloe-real-v1/blueprint.mjs <캐릭터팩> --view=side shoe-side legs

명령은 얼굴·전신 원본을 우선하는 순서와 요청 부위의 자료를 내보낸다. SHA-256 및 사각형의 원본 범위를 확인한다. 각도별 보조 자료와 질감 사진은 그 범위에서만 쓴다. 사진 조각을 직접 합성하거나, 옷에 가려진 부위의 3D 치수를 확정하는 기능은 없다.

### 기본 몸체·의상·구두 레이어

    node asset-library/chloe-real-v1/body-layers.mjs <캐릭터팩> --report > body-layers-report.json
    node asset-library/chloe-real-v1/body-layers.mjs <캐릭터팩> --html > chloe-body-blueprint.html
    node asset-library/chloe-real-v1/body-layers.mjs <캐릭터팩> --compare > chloe-body-comparison.html

정면 설계도에서 의상, 구두, 기준점을 각각 표시할 수 있다. 세 레이어는 같은 좌표와 배율을 공유한다. 보고서는 앞·뒤·좌·우·위·아래의 출처 상태와 치수의 픽셀 양끝을 담는다. 비율은 사진별 정수리부터 구두 접지까지의 높이를 100으로 둔 투영값이다. 오른쪽과 뒤는 방향 보조, 왼쪽은 보조 시트로만 연결한다. 위·아래, 정장 아래 골반 깊이, 맨발 크기는 자료가 들어오기 전까지 미확정으로 남긴다. 구두를 숨겨도 자세와 기준 바닥선은 그대로 유지된다.

v2는 턱 기준점을 y=215로 보정하고, 치마 아래부터 구두 입구 위까지 다리 윤곽의 좌우 가장자리를 사진의 20개 높이에서 따로 기록한다. 이 좌표는 정면 도식을 그릴 때도 그대로 사용한다. 비교 모드에는 원본 사진이 포함되므로 내부 검수에 사용한다.

v3는 오른쪽 보조 사진에서 치마와 구두 사이의 앞뒤 외곽을 20개 높이에서 추적한다. 비교 모드에서 사진의 측정선을 볼 수 있다. 측면 폭은 사진에서 두 다리가 겹쳐 보이는 투영값이다. v2의 정면 다리 좌표를 그대로 사용한다.

## 체형 고정

얼굴 비교를 통과해도 체형이 검증되지는 않는다. 이전 포즈 시안 5번은 사선 자세와 정면 체형 원본을 직접 비교할 수 없어 체형 미검증으로 둔다. 구두 포함 기준사진에 표시한 어깨, 재킷 허리, 무릎, 발목 위치는 정면 비교용 2D 좌표다.

    node asset-library/chloe-real-v1/geometry.mjs measure <정본-폴더>
    node asset-library/chloe-real-v1/geometry.mjs compose <정본-폴더> <장면.json> <결과.svg>

장면 입력 예시:

    {"mode":"approved-front","width":1600,"height":900,"x":520,"y":30,"scale":0.55,"background":"#E8E4DE"}

원본 PNG와 원본 사진 배경을 포함한 프레임을 그대로 쓰며, 위치·균일 확대·축소와 바깥 캔버스 색을 바꿀 수 있다. 원본 해시, 프레임 치수, 화면 안 배치를 검사한다. 비균일 확대나 프레임 잘림은 거절한다.

새로운 자세나 카메라 각도에 동일한 비율을 보장하려면 승인된 메시·관절 위치·기본 자세·구두 모델이 필요하다. 이 자료가 아직 없는 동안 새 시점 요청은 실행을 중단한다. 생성 도구가 다른 자세나 옷을 직접 다시 그린 이미지는 시안으로 다룬다.
