## 명확한 기준
1. 원래 승인된 차콜 정장 전신 **정면** PNG의 해시를 항상 검증한다. 독립적인 새 얼굴을 1차 기준으로 쓰지 않는다.
2. 성인 기본 외형 시안은 **불투명한 스포츠 브라형 상의와 몸에 붙는 짧은 운동 반바지**, 맨발 참고. 가슴·골반·엉덩이·음부를 가린다. 실제 3D/신체 스캔이 아니다.
3. 생성된 인포그래픽에 포함된 키·몸무게·둘레·발 크기 등의 숫자는 **모두 가짜 레이아웃 숫자**이므로 무효이다. 실제 길이·둘레를 추정하거나 스키마의 규격값으로 등록하지 않는다.
4. 새 기본형 정면/45도/측면/후면, 표정, 자세, 의상은 전부 **REVIEW_ONLY**. 완성된 하나의 공통 리그에서 추출한 이미지가 아니라서 자동 동일성 승격을 금한다.
5. 허벅지·무릎·종아리·발목, 어깨/골반, 머리-몸 비율, 관절의 의상 관통·접촉·주름을 수동으로 검수한다.
6. 현재 로봇형 CLO-02 정본과 `characters/클로이` 가운데 B안 외형은 건드리지 않는다. 또한 AI Studio 웹 서비스 배포를 완료했다고 주장하지 않는다.

## 다음 실무 기준
- 표준: 6각도 × 8자세 × 7착장 전체를 한꺼번에 생성하지 않는다. **기본 정면과 양측면, 좌·우 45도, 후면**을 먼저 승인하고, 그 후 정장 착장과 앉기/팔올리기 2포즈로 좁혀 조합 검증한다.
- 같은 정면 이미지의 스타킹 **색상** 변경은 기존 BODY_LOCK 마스크로 RGB 바깥 픽셀 0개 변경 검사 가능.
- 다른 각도/포즈/의상에서 진짜 같은 몸을 보장하려면 승인된 공통 3D 몸 메시·리그와 의상 별도 메시가 필요하다. 생성형 이미지 샘플의 비주얼 유사성 점수만으로 확정하지 않는다.

기본 원본을 덮어쓰거나 승인 상태를 바꾸는 자동화 코드는 이 PR에 포함되지 않는다.
