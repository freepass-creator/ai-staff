# 카카오톡 프로필 선택

`library.json`에 등록된 02 사진 한 장만 사용한다. 원본 PNG와 SHA를 그대로 유지하며 새로 그리지 않는다.

대표가 나머지 프로필 사진을 전부 폐기했다. 이전 01·03·04 프로필, 02의 다른 시안, ZIP·비교표·생성 캐시·과거 대화 첨부에서 대체 사진을 가져오지 않는다. 등록되지 않은 번호는 현재 사용 가능한 프로필 사진이 없는 상태다.

캐릭터 디자인 원본과 블로그 활용 이미지는 별도 자산이며 카카오톡 프로필의 대체 이미지가 아니다. 공개 AI 진입점은 `/profiles.json`이다.
