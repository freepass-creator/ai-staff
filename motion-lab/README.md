# 현재 클로이 모션 준비 상태

최신 SVG 키트: `robots/svg-release.json` 및 `robots/SVG-RELEASE.md`. `/gestures/`는 작은 정면 2D 동작을 제공하며, PNG 없는 관절 경로본과 질감을 내장한 웹 재생본을 구분한다. 아래 표는 최초 `/motion/` 시험의 범위다.

이번 요청은 가능 상태 확인이다. 현재 카탈로그의 최신 정본과 활용 이미지를 점검하고 작은 동작 시제품만 만든다. 구버전 모션·정지된 rig를 현재 정본으로 다시 연결하지 않는다.

| 동작 | 현재 상태 | 근거 |
|---|---|---|
| 살짝 살랑이는 몸 | 2D 시제품 가능 | 고정 이미지의 작은 발끝 기준 회전·이동 |
| 눈 깜박임 | 기술시험, 완성 전 | 닫힘 때 검은 화면 반사 경계가 남음. 분리 레이어 필요 |
| 눈동자·표정 교체 | 추가 제작 필요 | 현재 표정별 독립 화면 레이어 없음 |
| 팔·손목 독립 동작 | 준비 필요 | 최신 소스의 부위 분리·숨은 면·관절 정의 없음 |
| 손·손가락 접고 펴기 | 현재 준비 안 됨 | 손가락별 마디/관절축/가림 순서/손바닥·손등 형태가 없음 |
| 자유로운 3D 동작 | 현재 준비 안 됨 | 메시·스킨·3D 리그가 없음 |

SVG는 코드로 된 고정 정면 픽셀 경로다. 파일 형식이 SVG라는 이유로 손가락 관절이 생기지 않는다. 38개 활용 사진도 자세별 독립 그림이지 하나의 움직일 수 있는 모델이 아니다.

시제품은 현재 library의 `01-welcome` 파생 PNG를 고정 해시로 읽는다. 정본 PNG·SVG를 수정하지 않으며 이 시제품을 새 정본으로 지정하지 않는다. 6초 영상과 브라우저 제어는 같은 렌더 함수를 사용한다. 몸은 최대 약0.315도 미세 회전이며 손가락을 움직였다고 주장하지 않는다.

보기: `http://127.0.0.1:54640/motion/`. 기본 재생과 내려받는 영상에는 몸 살랑임만 포함한다. 눈 시험은 체크박스로 따로 켠다. 정본 이미지 전체를 기울이는 방식이므로 관절에 따른 체중 이동은 아니다.

눈의 발광 픽셀을 세로로 압축하고, 비워진 부분은 인접한 검은 화면 행을 샘플링해 근사한다. 초기 방식의 프레임 찌그러짐을 피하기 위한 시제품이며, 눈 주변 유리 반사는 완전히 보존되지 않는다. 눈썹·입·프레임 바깥을 고정한 상태의 차이를 검증한다. 실제 눈꺼풀이나 독립 표정 레이어를 만든 것은 아니다. 정상 제작에는 깨끗한 화면 바탕과 발광 표정의 분리 레이어가 필요하다.

다음 단계는 최신 정본 기준으로 부위를 정확히 분리하고, 가려지는 배경과 관절 연결부를 만든 뒤 손가락의 굽힌 모양을 확인하는 것이다. 손가락을 제대로 접고 펴려면 검증된 2D 손 리그 또는 3D 손 메시·리그가 필요하다. 어느 경로든 정지 자세에서 현재 외관과 맞대어 검수해야 한다.
