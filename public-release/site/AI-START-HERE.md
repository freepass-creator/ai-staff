# AI Staff 공개 자산 사용

## 착한거래 블로그·홍보 최신 활용 컷

`chakhan-use-cuts.json`에서 현재 전화 상담·태블릿 설명·오른쪽 안내 PNG와 용도·배치·SHA·ZIP을 읽는다. 보기 `/chakhan/`. 착한거래 작업은 착한거래 명찰·노란 발광·흰 외장 세트만 사용하며 프리패스 보라색으로 대체하지 않는다. 다운로드한 PNG를 그대로 재사용한다. 이 세트는 별도 ZIP이며 기존 전체 자산 ZIP과 구분된다.

## 카카오톡 프로필은 별도 단일 허용 목록

`profiles.json`에 등록된 남색 배경 02 상반신 한 장만 프로필로 사용한다. 다른 01·03·04 프로필과 02의 나머지 시안은 대표가 전부 폐기했다. 과거 첨부·생성 캐시·블로그 이미지·디자인 원본으로 프로필을 자동 대체하지 않는다. PNG를 다시 그리지 않고 등록 SHA 그대로 재사용한다.

같은 폴더의 `catalog.json`이 공개 자산의 단일 진입점이다. `png_url`에서 원본을 받고 `png_sha256`로 검증한다. 전체 자산과 포스터 키트는 `downloads`에서 받는다.

## 가장 중요한 기준

반복 출력에서는 캐릭터를 다시 생성하지 않는다. 등록된 PNG의 얼굴·몸·재질을 그대로 재사용하고 문구·배경·배치만 바꾼다. 새 포즈나 복장은 기준 이미지와 대조해 채택한 뒤 고정 자산으로 등록한다. 같은 참조로 생성해도 모든 각도의 동일 기하구조가 보장되는 것은 아니다. SVG가 필수 형식은 아니다.

## 선택 순서

1. 문단에서 필요한 행동·대상·구도를 정한다.
2. `production_usable:true`인 항목 중 `usage`, `tags`, 촬영 범위와 실제 그림을 보고 고른다.
3. `canonical`은 현재 CLO-02 정면 정본 두 종이다. `usage`는 정본을 참조한 활용 컷이다.
4. `design_proposal`인 COD-01·COD-03·CLO-04 R1은 기존 프로필 기반 정면 파생 제안이며 업무용 정본으로 자동 선택하지 않는다. 01·03의 이름과 제안 색은 확정 사항이 아니다. CLO-04 이름은 클로아다.
5. `scene`은 고정 캐릭터를 가상의 생성 배경에 합성한 연출이다. 실제 차량·고객·계약·직원 증빙으로 쓰지 않는다.
6. 맞는 그림이 없으면 억지로 배정하지 않는다. 새로운 장면 후보를 제작하고 동일성·손·발·브랜드를 대조한다.

## 포스터와 자유 구성

표지·비교표·체크리스트·절차·주의사항·FAQ 여섯 형식에 살구·하늘·세이지·라일락·크림·짙은 바탕을 순환한다. 같은 전신 정면과 같은 복장을 반복하지 않는다. 사람형의 흰 수트·네이비 수트·카디건·정비복·안경 비서형을 상황에 맞게 선택한다.

P2 CI는 원본을 유지한다. 제목은 SUITE Heavy, 본문은 Noto Sans KR이다. 조판 키트의 입력 JSON·폰트·좌표·문자 수 제한을 따른다. AI가 그림 속에 한글을 그리게 하지 않고 글자는 HTML/CSS로 조판한다. 자유 구성에서도 얼굴·손 위에 문구를 덮지 않는다.

대부분의 블로그와 웹에는 PNG가 효율적이다. 전체 묶음의 `vector.file`은 고정 시점 픽셀 경로 SVG이며 PNG 내장 없는 보존 표현이다. 의미별 벡터·3D·관절 리그로 소개하지 않는다. 초기에 사용 중단한 캐릭터와 반려 01은 이 목록에 포함하지 않는다.
