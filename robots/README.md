# 로봇 캐릭터 기준과 기존 이미지 정리

## 최신 착한거래 단일 외형 기준 (대표 확정 2026-11-13)

착한거래에서 사용하는 클로이는 **CLO-02-CHAKHAN, 흰색·은색 외장/노란 눈의 기존 다각도 10장 세트 한 가지**다. 기준은 `robots/CLO-02/chakhan-sales/motion-3d/assets/chloe-*.webp`, 목록과 원본 해시는 `studio/turnaround/reference-index.json`에서 확인한다.

과거 확인된 노란색 `clo02-thumbs-up`, `clo02-compare`, `clo02-consultation`, 마케팅 포즈 및 아래의 `형광 노랑 빛의 착한거래 로봇.png`는 **이전 자산/검토 기록**으로 보존한다. 이 자산들은 현재 승인된 **단일 다각도 기준 외형의 대체재가 아니며**, 착한거래 게시용 이미지·영상으로 자동 채택하지 않는다. 공식 보라색 CLO-02와 CLO-04 클로아도 착한거래용으로 혼합하지 않는다.

기존 기준으로 만들어진 2D 모션은 외형을 대조하는 연구용이다. 10방향에 일치하는 신규 모션은 검수 후 별도 승인한다.

| CLO-02 | 클로이 | 보라색 공식 원본 + 착한거래용 노란색 변형(같은 캐릭터) |

새 표시 형식은 **CLO-02 · 클로이**, **CLO-04 · 클로아**로 통일한다. 검색용 `CLO02`, `clo02`, `CLO 02`는 CLO-02의 번호 별칭이며 다른 캐릭터가 아니다. CLO-04도 같은 원칙을 따른다.

## 확인한 이미지와 혼재 원인

**확정 운용 구조:** `CLO-02` 기본(보라색)과 `CLO-02-CHAKHAN`(노란색 착한거래용 변형)을 한 캐릭터의 서로 다른 자산으로 관리한다. `CLO-04` 클로아는 별도 캐릭터다. 블로그·영상에서 어떤 버전을 쓰는지는 브랜드 프로필로 선택한다. 색상이나 마킹만 보고 새로운 ID를 만들지 않는다.


2026-11-11 기존 파일 3개의 실제 픽셀을 대조했다. 아래 파일명은 출처를 찾기 위한 원래 이름이며, 저장소에 이미지가 들어 있다는 뜻은 아니다.

**최신 확인(2026-11-12): 착한거래의 노란색 로봇은 공식 CLO-02 클로이를 브랜드에 맞게 변경한 정식 변형이다.** 같은 캐릭터의 두 자산이며 보라색 정본을 노란색 이미지로 대체하거나, 노란색을 별도 CLO-04로 개명하지 않는다. 기존 주황 원본과 각각의 원본 파일 대응·파생 이력은 계속 개별 검증한다.

보라 원본 후보는 1254×1254 PNG이며 알파값이 모두 255다. **투명 배경 파일이 아니다.** 이름 정비와 배경 제거·명찰 수정·새 자세 생성은 별도 작업이다.

## 정리 순서

1. 번호·이름은 registry의 최신 확정으로 통일한다.
2. 원본을 보존한 채 이미지의 얼굴 화면·눈·입·볼 표시·안테나·귀 구조를 대조한다.
3. 착한거래 노란색 자산을 CLO-02의 브랜드 변형으로 사용하되, 기존 주황 원본의 파생 관계와 CLO-04 원본은 따로 확인한다.
4. 확인된 캐릭터만 `<ID>-<브랜드>-<자세>-vNN.png` 형식으로 파생본을 만든다. 브랜드·자세·버전은 필요한 경우에만 붙인다.
5. 파일명, 문서의 이름·번호, 이미지 안 명찰을 각각 확인한다. 파일명만 바꾸고 완료로 처리하지 않는다.
6. 웹페이지에서 쓰는 파일 경로를 바꿀 때에는 해당 참조도 함께 수정하고 실제 화면을 검증한다.

## 기존 착한거래용 10방향 원본 위치 (2026-11-12 회수)

대표가 이미 제작했다고 언급한 8방향+상·하 10장은 **착한거래 Draft PR #11**의 `motion-3d/assets/chloe-*.webp`에 있다. 당시 main이 아닌 `codex/chloe-pt-continuation-20261112` 브랜치에 있어 main만 조회하면 보이지 않았다. AI Staff 작업 브랜치에는 `robots/CLO-02/chakhan-sales/motion-3d/assets/`로 **원본 바이트 그대로** 10장 복사했으며 `studio/turnaround/reference-index.json`에 SHA 기록했다. 참조 영상/손가락 PT는 원래 착한거래 브랜치의 `motion-3d/PT-HANDOFF.md`를 확인한다. 새 이미지 생성이나 공식 보라색 기본 원본 대체 작업이 아니다.

## 새 이미지 주문서에 넣을 정보

- 캐릭터: 공식 번호와 한국어 이름.
- 원본: 실제 첨부 이미지 또는 검증된 원본 파일. 글 설명만으로 재창작하지 않는다.
- 고정 요소: 원본의 얼굴 화면·눈·속눈썹·입·볼 표시·안테나 유무·헤드셋 귀·핀·몸 비율.
- 변경 요소: 이번 작업에서 지시받은 브랜드 색·명찰·자세·구도만.
- 색상 변형은 캐릭터 번호 변경 사유가 아니다. 동일 원본과 번호의 연결이 확인되어 있어야 한다.
- 출력의 번호나 형태가 기준과 다르면 새 기준으로 등록하지 말고 수정 대상으로 남긴다.

## 실행 경로

PC 조작·파일 검색·캡처 등 원격 실행은 AI Link를 우선한다. RDC는 이 프로젝트의 작업 경로로 사용하지 않는다. AI Link 실제 실행 결과는 별도 영수증/화면 증거로 검증하고, GitHub 기록 수정만으로 PC 화면에 반영됐다고 표시하지 않는다.

## 적용 범위

이 레지스트리는 로봇 이름·번호 및 자산 대조용이다. 기존 `generator/`의 사람형 생성·SFace 검사에 바로 입력하는 설정이 아니다. 기존 클로운·클로담 사람형 폴더, PC 번호·호스트·업무 담당은 이번 정비로 바꾸지 않는다.
