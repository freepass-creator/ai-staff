# 클로이 SVG 원본 대조 기준

기준은 `current.json`에 등록된 승인 PNG 두 종이다. 이전 V1 이미지는 손바닥·손등 재질을 대조하는 이력 자료이며 현재 정본으로 되돌리지 않는다.

- 손바닥: 검정에 가까운 짙은 차콜 회색. 손등·손가락 바깥 외장: 흰색 도장. 관절 틈: 짙은 회색. 손 LED 없음.
- 얼굴: 검은 유리 안의 발광 표정. 흰 도장 반사, 은은한 발광, 명찰 미세 도트와 원래 비율을 보존한다.
- 재구성: `rebuild-svg.py`가 원본 SHA를 확인한 뒤 색별 가로 픽셀 런을 SVG path로 기록한다. 내장 PNG, 외부 이미지 참조, 색상 축약이나 재도색을 사용하지 않는다.
- 검증: 1024×1536에서 Resvg와 Edge 실제 렌더링 모두 원본과 RGBA 차이 0. 모든 불투명 픽셀을 한 번씩 덮는지도 확인한다.
- 범위: 고정 정면 픽셀 경로이며 형태별로 편집하는 벡터, 손가락 관절, 3D 모델이 아니다. 확대·축소 시 PNG와 동일한 샘플링을 보장하지 않는다. 사이트는 승인 PNG를 표시하고 SVG는 원래 크기 기준으로 제공한다. 블러로 원본을 변형해 매끈하게 보정하지 않는다.

비교 캡처 오른쪽은 SVG를 원래 크기로 실제 렌더링한 뒤 PNG로 캡처한 결과다. 임의 크기의 직접 SVG 표시와 혼동하지 않는다.
