# 웹툰 스튜디오 공통 캐스팅 단일 바디 프로필 규격

버전: `CASTING-BODY-v2.1`  
최종 수정: `2026-09-08`  
적용 범위: 이 저장소의 모든 웹툰과 모든 성인 캐릭터  
원칙: **배우 한 명당 공식 캐스팅 자료는 한 장짜리 수영복 바디 프로필로 끝낸다.**

[실제 배우를 넣지 않은 공통 양식 샘플 →](assets/casting/CASTING-BODY-SAMPLE.md)

## 1. 필수 결과물

- 사용자에게 보여주는 공식 결과물은 후보별 `body-profile.png` 한 장이다.
- 한 장 안에 후보명, 정면·옆면·뒷면 전신, 키 눈금, 나이·키·몸무게를 모두 넣는다.
- 얼굴 표정표, 의상 룩북, 자세·동작표, 상대 배우 호흡표는 기본 캐스팅 단계에서 만들지 않는다.
- 사용자가 나중에 특정 시험을 별도로 요청한 경우에만 추가한다.
- 이전에 만든 여러 장의 시험 자료는 기록으로 보존할 수 있지만 공식 캐스팅 화면에는 펼치지 않는다.

## 2. 한 장 구성

1. 상단 제목: `후보 번호 · 한글 이름`
2. 동일 배우의 머리부터 발끝까지 보이는 정면 전신
3. 동일 배우의 정확한 90도 옆면 전신
4. 동일 배우의 뒷면 전신
5. 세 전신이 공유하는 0~200센티미터 키 눈금과 0센티미터 발바닥 기준선
6. 정수리는 설정 키 눈금에 맞춘다.
7. 하단에는 `나이 · 키 · 몸무게`만 표시한다.

- 제목과 항목은 한글로만 쓴다.
- 별도 얼굴 확대, 설명문, 배역 소개, 장식 문구를 사진 안에 넣지 않는다.
- 세 전신은 같은 얼굴, 헤어, 체형, 의상, 조명, 카메라 높이와 배율을 유지한다.
- 정면은 렌즈를 똑바로 보고, 옆면은 정확한 측면, 뒷면은 완전히 뒤를 본다.
- 팔은 자연스럽게 내리고 맨발로 중립 자세를 취한다.
- 머리·손·발을 자르지 않는다.

## 3. 공통 수영복

- 모든 후보는 명시적인 성인으로 설정한다.
- 같은 배역군은 동일한 불투명 흰색 투피스 수영복을 입는다.
- 기본형은 몸에 맞는 흰색 운동용 크롭 래시가드와 흰색 수영 쇼츠다.
- 소재는 비치지 않고 장식·로고·신발·액세서리를 넣지 않는다.
- 체형 비교를 위한 촬영이므로 선정적인 표정이나 자세를 쓰지 않는다.
- 후보별로 옷의 길이와 면적을 임의로 바꾸지 않는다.

## 3-1. 가상 성인 여배우 공통 체형 기준

2026-09-08 사용자 지시에 따라, 모든 작업 세션에서 새로 생성하거나 재생성하는 가상 성인 여배우에게 다음 기준을 공통 적용한다. 공식 바디 프로필뿐 아니라 사용자가 별도로 요청한 의상·포즈 테스트에도 동일하게 적용한다.

- **기본 가슴 볼륨은 꽉 찬 B컵~C컵 정도의 자연스러운 크기**를 목표로 한다. 가슴만 과장해서 크게 만들거나 비현실적인 볼륨을 부여하지 않는다.
- 얼굴 크기·키·어깨·흉곽·허리와 균형 잡힌 현실적인 전체 비율을 우선한다. 가슴 크기를 조정한다는 이유로 얼굴, 키, 체중, 나머지 체격을 임의로 바꾸지 않는다.
- 동일 배우의 정면·측면·뒷면과 의상·포즈 변경본은 같은 기준 체형을 유지한다. 의상 변경이나 카메라 각도를 이유로 가슴 볼륨을 임의로 부풀리지 않는다.
- 컵 표기는 제작상의 시각적 목표로만 기록한다. 생성 이미지에서 실측 또는 정확한 컵수가 검증되었다고 표시하지 않는다.
- 최종 검수에서는 과도한 가슴 확대, 얼굴·신체 비율 왜곡, 컷마다 달라지는 체형을 확인하고, 해당 문제가 있으면 승인 전에 수정한다.
- 기존 이미지와 확정본은 이 기준 변경만으로 자동 수정하거나 덮어쓰지 않는다. 기존 배우의 재작업은 사용자가 요청한 범위에서 진행한다.

## 4. 화면과 파일

후보별 기본 구조:

```text
작품/characters/candidates/후보코드/
  body-profile.png
  README.md
  profile.md
  prompt.md
```

- 후보 `README.md`에는 `body-profile.png` 한 장만 바로 펼친다.
- 사진을 누르면 GitHub 원본이 열리게 한다.
- 화면 위와 아래에는 캐스팅 목록으로 돌아가는 링크를 둔다.
- 프로필 수치와 생성 기준은 내부 관리용 `profile.md`, `prompt.md`에 기록한다.
- 기존의 얼굴·표정·의상·자세 파일은 삭제하지 않아도 되지만 사용자용 화면에서 숨긴다.

## 5. 비교와 승인

- 모든 후보는 같은 세로 캔버스 비율, 같은 0~200센티미터 눈금, 같은 촬영 조건을 사용한다.
- 발바닥은 0센티미터선, 정수리는 설정 키에 정확히 맞춘다.
- 체중을 유지하라는 지시가 있으면 몸무게와 체격을 줄이지 않고, 운동으로 정돈된 탄력만 표현한다.
- 사용자는 후보별 한 장만 넘겨보며 얼굴·덩치·체형·다리선과 키를 비교한다.
- 확정 후보만 `characters/main/`의 캐릭터 바이블로 등록한다.

모든 이미지는 GitHub에 먼저 저장하고, 사용자에게는 사진이 즉시 펼쳐지는 GitHub Markdown 바로보기 링크를 제공한다.
